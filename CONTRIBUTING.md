# Contributing to Timeslotfit

Thank you for your interest in contributing to Timeslotfit! We welcome contributions from the community to help improve the project.

## How to Contribute

### Reporting Bugs
If you find a bug, please open an issue on GitHub with:
- A clear title and description
- Steps to reproduce
- Expected vs. actual behavior
- Your environment (browser, OS, etc.)

### Feature Requests
For new features or improvements, open an issue describing:
- The problem you're trying to solve
- Your proposed solution
- Any alternatives considered

### Contributing Code

1. Fork the repository on GitHub
2. Clone your fork: `git clone https://github.com/your-username/timeslotfit.git`
3. Create a feature branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Run linting: `npm run lint`
6. Commit your changes: `git commit -m "Add your message"`
7. Push to your branch: `git push origin feature/your-feature-name`
8. Open a Pull Request on GitHub

### Code Standards
- Follow the existing code style
- Use TypeScript for type safety
- Write clear, concise commit messages
- Ensure code passes linting checks

### Testing
We aim to add comprehensive tests in the future. For now, manually test your changes to ensure they work correctly.
