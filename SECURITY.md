## Reporting a Vulnerability

If you discover a security vulnerability in Timeslotfit, please report it responsibly. We appreciate your help in keeping our users safe.

### How to Report

- **Do not** create public GitHub issues for security vulnerabilities
- Send a detailed report to: [INSERT EMAIL, e.g., security@timeslotfit.com] or [GitHub Security Advisories](https://github.com/magnusfroste/timeslotfit/security/advisories/new)
- Include:
  - Description of the vulnerability
  - Steps to reproduce
  - Potential impact
  - Any suggested fixes

### Our Response Process

1. **Acknowledgment**: We will acknowledge receipt of your report within 48 hours
2. **Investigation**: We will investigate and validate the vulnerability
3. **Fix Development**: If confirmed, we will develop and test a fix
4. **Disclosure**: We will coordinate disclosure with you and release the fix
5. **Credit**: We will credit you in the release notes (unless you prefer anonymity)

### Guidelines

- Please allow reasonable time for us to respond and fix the issue before public disclosure
- Do not perform active exploitation or share details publicly
- We follow responsible disclosure practices
